About OfficeConnectPro

How OfficeConnectPro started, what we’re trying to build, and who’s behind it.
Tip OfficeConnectPro is an independent site and is not affiliated with, endorsed by, or connected to Workday, Inc. in any way. See the Legal Disclaimer for full details.

OfficeConnectPro is an independent documentation site for Workday OfficeConnect. Workday’s official docs have always been scattered and hard to navigate, so this site exists to give practitioners one clear, honest place to find answers — whether you’re building your first report, managing a deployment, or troubleshooting something that’s gone sideways.

Helpful resources

Official Workday documentation

  • doc.workday.com — Workday’s official product documentation, including the full OfficeConnect guide, release notes, and administrator references
  • Workday Community — peer forum, Workday-authored articles, and the primary place to log support cases (requires a Workday account)
  • Workday Training & Certifications — role-based learning paths including Adaptive Planning and reporting tracks

Workday Adaptive Planning

  • Adaptive Planning documentation — covers the planning model, version management, and the data that OfficeConnect connects to
  • Adaptive Planning release notes — track what changed in each release, including OfficeConnect-specific entries

Microsoft Excel & Office

  • Microsoft Excel help & learning — official Excel documentation, formula reference, and how-to guides
  • Microsoft 365 admin center docs — relevant for IT teams managing Excel add-in deployment via Intune or the Microsoft 365 admin center
  • Office Add-ins documentation — useful background for admins troubleshooting COM add-in registration or deployment

Community & discussion

  • r/workday — active subreddit covering Workday Adaptive Planning, Financials, and OfficeConnect questions
  • r/excel — broad Excel community; useful for Excel-side questions that come up when building OfficeConnect reports

Related tools

  • Power Automate — used alongside OfficeConnect for scheduled refresh workflows and automated distribution
  • SharePoint & OneDrive for Business — common storage layer for shared OfficeConnect workbooks

Stay connected

  • YouTube — youtube.com/@officeconnectpro — video walkthroughs, tips, and release coverage
  • GitHub — github.com/s-mcintosh/officeconnectpro — source for this site
