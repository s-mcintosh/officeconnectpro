OfficeConnect is a Microsoft Office add-in that pulls live data from Workday Adaptive Planning directly into Excel, Word, and PowerPoint. This section covers everything you need to get up and running, build reports, and manage the platform.

- [First 30 Minutes](/wiki/first-30-minutes/) — Install, sign in, build your first report, and refresh it — a complete onboarding path in half an hour
- [System Requirements](/wiki/system-requirements/) — Hardware and software prerequisites before installing OfficeConnect
- [Install (End User)](/wiki/install-end-user/) — Install OfficeConnect on your own machine without requiring IT involvement
- [Install (IT Admin)](/wiki/install-admin/) — Deploy OfficeConnect to multiple users using per-machine installation and group policy or scripts
- [Check Your Version](/wiki/check-version/) — How to check which version of OfficeConnect you have and update to the latest release
