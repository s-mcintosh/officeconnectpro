What's New in Workday OfficeConnect 2026R1

Workday OfficeConnect 2026R1 (released March 14, 2026) introduces View By in the ribbon, personal what-if scenarios for end users, and the latest forced-upgrade prompt at sign-in.

View By — Open Cell Data in a New Sheet (2026R1)

The 2026R1 View By ribbon command opens the data behind any Workday OfficeConnect cell in a separate worksheet so you can slice and filter without breaking your main report.

Personal What-If Scenarios (2026R1)

Workday OfficeConnect 2026R1 lets end users create personal what-if scenarios without involving an Adaptive Planning admin — scoped to the individual, branched from a parent version, and invisible to others.
